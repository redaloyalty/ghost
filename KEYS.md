# Keys - Ghost desktop

Super = the Windows key.   q to close this.   Shown any time with Super + /

OPEN THINGS
  Super + Enter          terminal (kitty)
  Super + d              app launcher - type any app name
  Super + Tab            jump to any open window
  Super + b              Chrome            Super + Shift + b   Firefox
  Super + c              VS Code           Super + o           Obsidian
  Super + a              Claude Code (terminal in ~/ll)
  Super + e              ranger (files in terminal)
  Super + n              Files (normal file manager)
  Super + Shift + w      WhatsApp (laptop screen, workspace 6)
  Super + Shift + t      Teams (laptop screen, workspace 6)

MIND (the laptop LLM)
  Super + Space          ask mind one question
  Super + m              chat with mind
  Super + i              laptop + mind status
  bar, middle            left click = chat, right click = ask

WINDOWS
  Super + Shift + q      close window
  Super + h j k l        move focus (arrows work too)
  Super + Shift + h j k l   move the window
  Super + f              fullscreen on/off
  Super + \              next window opens beside
  Super + -              next window opens below
  Super + w              tabs     Super + s   stacked    Super + t   back to tiles
  Super + Shift + Space  float / unfloat window
  Super + r              resize mode (h j k l or arrows, Esc to leave)
  Super + drag           move a floating window with the mouse

SCREENS
  Ctrl + Alt + Left / Right          jump to the left / right screen
  Ctrl + Alt + Shift + Left / Right  take the window to the other screen

WORKSPACES
  Ctrl + Alt + 1..0      same as Super + 1..0
  Super + 1..5           big screen: 1 term, 2 web, 3 code, 4 notes, 5 mind
  Super + 6..0           laptop screen
  Super + Shift + 1..0   send window to workspace
  Super + ,              send the whole workspace to the other screen
  Chrome goes to 2, VS Code to 3, Obsidian to 4, WhatsApp + Teams to 6 by itself

SCREENSHOTS  (saved in ~/Pictures/Screenshots)
  Print                  whole screen (both screens)
  Shift + Print          drag a box
  Super + Shift + s      drag a box

SOUND
  bar VOL: left click   pick output (monitor / laptop speakers)
  bar VOL: right click  mute on/off      scroll = volume
  volume keys on the keyboard work too

SESSION
  Super + Escape         lock
  Super + Shift + e      menu: lock, log out, suspend, restart, shut down
  Super + Shift + c      reload config      Super + Shift + r   restart i3 (windows stay)

LOST?
  Super + Shift + e  then  log out  ->  at login click the gear  ->  pick Ubuntu
  = back to the normal desktop, nothing changed there.
